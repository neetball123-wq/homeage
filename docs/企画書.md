# 企画書（タイトル未定）

## ひとことで

見た目はふつうのホームページ。リンクを踏んで読み進めると、知らない世界の短い話がつながっていく。

## 形式

- 1つの場面が1ページ。
- 中身は物語のまま。ホームページらしさは、HTML と CSS にもともとある機能で出す。短編ごとに専用の部品は作らない（1本あたりの手間を増やさないため）。
  - 配置：行ごとに左・中央・右を変える（遠くにいる人は右寄せ、など）
  - 文字の大きさ：7段階（くしゃみは特大、ささやきは極小）
  - 余白：空行を重ねて、間や沈黙を出す
  - 選択肢：リンク、ボタン、プルダウン、ラジオボタン、チェックボックス、文字入力、左右に分かれたリンク
  - 注釈（※）
- フォーム部品はブラウザ標準の見た目のまま使う。
- ブラウザの「戻る」を押すと「このページの有効期限は切れています」と出る。前には戻れない。
- 時間制限は「このページは○秒後に自動的に移動します」で出す。時間切れも1つの選択として記録する。時間制限は大事な場面だけにする（短編1本につき多くて1回）。

## 世界

- 人間以外の、いろいろな種族が住んでいる世界。
- 主役の種族はいない。短編ごとに、出てくる種族も人も変わる。
- 種族の設定は、どうでもいいところまで細かく決める（壁の厚さ、ポケットの大きさ、地図の書き方など）。
- 設定は本文で説明しない。会話のはしばしと注釈（※）に出す。注釈は読まなくても話はわかるようにする。

### 裏設定（前に出さない）

> ここは気づく人だけが気づけばいい。本文やタイトルで直接言わない。

むかし、この世界には「終わり」というきまりが1つだけあった。重すぎて誰も1人では持てなかったので、種族たちはそれを割って分けて持った。それぞれの種族の変わったきまりは、そのかけら。

- ゴロ：言葉が石になって残る（言葉に終わりがない）
- ヒトヒ：一日で一生が終わる（命の終わりをいちばん多く持っている）
- アマタ：「2」がない（ふたつに分かれる＝別れを持たない）

主人公は、きまりを何も持っていない。なぜなのかは最後まで言わない。

## 構成

- 短編集がたくさんつながっている形。
- 短編1本は3〜5分。1回の旅で6〜8本くらい読んで、だいたい30分。
- 短編どうしは、人、もの、場所でつながる。
  - 例：「くしゃみの石」でもらった石を、あとの短編で耳に当てられる（一度だけ聞こえる）。
  - 例：丘の上のスワリギは、別の短編の主役になる。
- 短編の終わりの分かれ道で、次の短編が決まる。
- どの選択も正解。やり直さなくても、1回の旅だけで話として成り立つようにする。

## リザルト

最後に「きろく」のページを出す。

- したこと（選んだことを順番に）
- 持っているもの
- 出会った人、別れた人（予定）
- 通ってきた短編のつながり（予定）

## 読むのが苦手な人向け

- 1ページはだいたい3〜6行。
- 地の文を少なくして、会話で進める。
- 選択肢は2〜3個まで。
- 文字は大きめ（18px）、行間は広め。読みやすさのために BIZ UDPゴシック を使う。

## 種族メモ

本文や注釈にちらっと出す用。増やしていく。

| 種族 | きまり | 細かい設定 |
|---|---|---|
| ゴロ | しゃべると言葉が石になる | 家は家族の言葉の石で建てる。けんかの多い家ほど壁が厚い。ささやくと砂になる。服のポケットが大きい。 |
| ウキシズ | 気持ちで体の重さが変わる | 子どもは足首に「おもし石」をつける。島ごと浮くので地図には「だいたいこのへん」。 |
| ヒトヒ | 朝生まれて夜に死ぬ | 一生で1文字しか書けない。412世代かけて1つの手紙を書いている。お昼の時点で中年。 |
| ナガナ | 名前の長さが寿命 | 長老は名乗るのに4分かかる。あだ名で呼ぶと寿命が縮むので、あだ名はいちばん深い友情のしるし。 |
| ウシロメ | 背中にしか目がない | 前を見てくれる「さきみ」と手をつないで歩く。「未来」のことを「まだ後ろにないもの」と言う。 |
| アマタ | 「1」と「たくさん」しか数えられない | 「ふたりきり」という考えがない。双子が生まれると、どちらが「ひとつ」かを決める儀式がある。 |
| ヒトクチ | 味が最後の一口にしか来ない | 最後の一口を誰に譲るかが、いちばんの愛情表現。 |
| スワリギ | 一度座ると二度と立てず、木になる | 最後に座る場所を一緒に探す「場所さがし」がいちばん尊敬される仕事。森はみんなご先祖。 |
| ツヅキウタ | 一族で1つの歌を歌い続けている | 800年続いている。息つぎは交代制。 |
| オチ | 話の結末しか覚えられない | 昔話は「めでたしめでたし」だけ。みんなそれで泣く。 |
| イロスイ | 見たものの色を吸ってしまう | ふだんは目を閉じている。見つめすぎた恋人は灰色になる。 |
