# 文章のルール

AIが書いた感じを出さないための決まり。書いたら、このリストで一度見直す。

## 使わない言葉

AIの文章によく出てくる言葉。見つけたら別の書き方にする。

- ぬくもり、静寂、優しい光、どこか懐かしい、胸の奥、心が温かくなる
- ふと、そっと、静かに（どうしても必要なときだけ）
- 紡ぐ、刻む、煌めき、儚い、かけがえのない、物語が始まる
- 「まるで〜のように」（比喩は短編1本に1つまで）
- ダッシュ（——）

## 書き方

- **気持ちは書かない。** 「悲しかった」「うれしかった」と書かずに、何をしたか、何が起きたかを書く。
  - ✕ 女の子はうれしそうだった。
  - ○ 女の子の口から、砂じゃなくて、小石がひとつ落ちた。
- **教訓を言わせない。** 「大切なのは〜なんだ」のようなセリフは書かない。
- **オチをきれいにしすぎない。** 毎ページ、余韻のある一文で終わらせない。投げっぱなしで終わるページがあっていい。
- **細かくて、どうでもいいことを書く。** 数字や生活感を入れる（壁が四十二センチ、ポケットが大きい、など）。
- **セリフは口で言う言葉にする。** 言いかけてやめる、話がずれる、返事になっていない、もあり。
- **登場人物を物わかりよくしすぎない。** ちょっと雑だったり、ずれていたりする人がいていい。
- **文の長さをそろえない。** 短い文ばかり、長い文ばかりにしない。
- **笑えるところは、説明しない。** 「おかしかった」と書かない。

## 感情を出す

- 人物ごとに、しゃべり方を変える。元気な人は「！」を多く、早口で、くり返す。悲しい人は、言いかけてやめる。怒っている人は短く言い切る。のんびりした人は語尾をのばす。
- 大きな声は `@4`〜`@7` と `*`（ゆれる）で大きく見せる。ささやきは `@1`。文字の大きさで声の大きさがわかるようにする。
- 一つの短編の中に、笑えるところと、しんみりするところの両方を入れる。全部が静かな話にしない。
- 子どもは、言いたいことをそのまま言う。「ずるい！」「やだ！」「もう一回！」。

## 見直すときのチェック

- [ ] 使わない言葉が入っていないか
- [ ] 気持ちを直接書いていないか
- [ ] どのページも同じリズムで終わっていないか
- [ ] 声に出して読んで、人が言いそうなセリフになっているか
- [ ] 注釈を読まなくても話がわかるか
- [ ] 元気な人、悲しい人、のんびりした人のしゃべり方がちがっているか
