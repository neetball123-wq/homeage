# homeage

さわって選ぶ、短編ストーリーのサイト。50の種族の短編から、1回の旅で6本を通る。

- 企画書：[docs/企画書.md](docs/企画書.md)
- 短編一覧（50本）：[docs/短編一覧.md](docs/短編一覧.md)
- 文章のルール：[docs/文章のルール.md](docs/文章のルール.md)

## 動かし方

`index.html` をブラウザで開くだけで遊べます。GitHub Pages で公開する場合は、このリポジトリのルートをそのまま公開してください。

## ファイル

- `index.html`：外枠（ヘッダー、きろくの板、確認の窓）
- `style.css`：見た目と動き
- `engine.js`：短編の読みこみ、ページの表示、さわって選ぶ部品、時間制限、きろく
- `stories/hajime.js`：はじまり（読み込み画面と、暗い場所）
- `stories/l1.js` 〜 `l6.js`：1段目から6段目の短編
- `stories/owari.js`：おわり（きまりを持って帰るか、旅のきろく）

## 短編の書き方

```
HOMEAGE.story(`
id: kushami
title: くしゃみの石
species: ゴロ
rule: しゃべると、言葉が石になる
layer: 1

# start
place: ゴロの村 ＞ 道
足もとに、石が転がってきた。
!「くしゃみだから」
ui: drag hint=石をつまんで、運ぶ
* 耳に当てる -> ear
* ポケットに入れる -> pocket | get=おばさんのくしゃみの石 log=石をポケットに入れた。

# ear
...
`);
```

- `# 名前` からが1ページ。行き先は、同じ短編なら `名前`、ほかの短編のはじめなら `@kushami`、おわりなら `@end`。
- `* 文 -> 行き先 | 効果` が選択肢。効果は `log=`（きろくに残す文）、`set=a,b`（フラグを立てる）、`unset=`、`get=`（持ちものをもらう）、`lose=`（手ばなす）、`need=`（持っているときだけ出る）、`if=` / `unless=`（フラグで出し分け）、`clear=名前`（入力された言葉を消す）、`alt`（部品の下に小さく出す）。
- 行の頭に `?flag ` をつけると、そのフラグがあるときだけ出る。`?!flag` はないとき、`?+持ちもの` は持っているとき、`?-持ちもの` は持っていないとき。選択肢の行にもつけられる。
- ページに書ける設定：`place:` `log:` `get:` `lose:` `set:` `unset:` `var: 名前=言葉` `note:`（※の注釈）`ui:` `hide:` / `hide*:` / `decor:`（下の部品用）`timer: 秒 -> 行き先 | log= label=`。

### 文章の行の頭の記号

| 記号 | 意味 |
|---|---|
| `@1`〜`@7` | 文字の大きさ（ふつうは `@3`） |
| `<` `^` `>` | 左から・中央（ふつう）・右から |
| `!` | 小石が落ちる（ゴロの人のセリフ） |
| `~` | 砂がこぼれる（ささやき） |
| `*` | 画面がゆれる |
| `{{名前}}` `{{名前\|なかったとき}}` | 入力された言葉 |
| `※` | 押すと `note:` の注釈が出る |

`@5>!` のように組み合わせられます。本文には `<span class="sway">`（ゆれる）、`float`（浮く）、`sink`（沈む）、`fade`（うすくなる）、`marquee`（流れる）も書けます。

### 選ぶ部品（`ui:` の最初の言葉）

| 部品 | さわり方 | 選択肢の使われ方 | 書けるもの |
|---|---|---|---|
| なし | リンクを押す | 全部 | |
| `buttons` | ボタンを押す | 全部 | `label` |
| `cards` | カードを1つ選んで決定 | 全部 | `label` `submit` |
| `chips` | いくつでも選んで決定 | 選んだものの効果が全部効く | `label` `submit` `to` `log`（`{n}` が数）`noneLog` `noneSet` |
| `select` | ドロップダウン | 全部 | `label` `submit` |
| `input` | 文字を書いて送る | 使わない | `label` `live` `submit` `name` `set` `to` `log` `empty` `emptyLog` `emptySet` `max` `lens`（文字数でフラグ） |
| `drag` | つまんで枠へ運ぶ | 枠になる | `hint` `item` |
| `hold` | 長押し。長さで変わる | 短い順 | `label` `hint` `steps`（切りかわる秒数） |
| `swipe` | カードを左右にはらう | 1つめが左、2つめが右 | `card` `hint` |
| `rub` | 押したまま左右にこする | 1つめ | `label` `hint` `count` |
| `spot` | 暗いところをなぞってのぞく | 1つめ（`hide*:` を見つけると押せる） | `bg` `hint` と `hide:` 行 |
| `spots` | 場面の中の点を押す | 選択肢に `x=` `y=`（%）、`shape=stone` `fx=rollin` | `ratio` `hint` と `decor:` 行 |
| `field` | 暗い中を照らして、見つけた点を押す | 選択肢に `x=` `y=` | `hint` |
| `boot` | 99%で止まる読み込み。長押しで100% | 1つめ | `label` `stuck` `hold` |

`timer:` だけ書いて選択肢を書かなければ、「待つ」ページになります。

## たしかめかた

ブラウザの開発者ツールで `HOMEAGE.debug.auto()` を呼ぶと、今のページでランダムに1つ選んで進みます。`HOMEAGE.debug.fast = true` にすると、動きを待たずに進みます。
