# homeage

ホームページの見た目をした、選択式の短編ストーリー。

- 企画書：[docs/企画書.md](docs/企画書.md)
- 文章のルール：[docs/文章のルール.md](docs/文章のルール.md)

## 動かし方

`index.html` をブラウザで開くだけで読めます。GitHub Pages で公開する場合は、このリポジトリのルートをそのまま公開してください。

## ファイル

- `index.html`：ページの外枠
- `style.css`：見た目
- `engine.js`：ページの表示、選択、時間制限、記録
- `stories/`：短編の中身。1本につき1ファイル

## ページの書き方

```js
HOMEAGE.add([
  {
    id: 'kushami.where',          // 短編名.ページ名
    place: 'ゴロの村 ＞ 道',        // 右上に出る場所
    text: [
      '@7ぶえっくし。',              // @1〜@7 で文字の大きさ（ふつうは @3）
      '>少し先で、おばさんが…',       // < 左寄せ　^ 中央（ふつう）　> 右寄せ
      '@1>ころん',                   // 組み合わせもできる
      '',                            // 空行。重ねるほど間があく
      '「ウキシズ※より遠い？」',        // ※ は notes の順に番号がつく
      '「{{from}}、ねえ」',            // 入力された文字を出す
      { if: 'waved', text: '…' },    // フラグがあるときだけ出す（unless で逆）
    ],
    notes: ['ウキシズ　気持ちで体の重さが変わる人たち。'],
    ui: { type: 'buttons' },        // 選択肢の出し方（下の表）
    choices: [
      { text: '耳に当てる', to: 'kushami.ear' },
      { text: '手をふる', to: 'kushami.wave', log: '手をふった。', set: { waved: true } },
    ],
    timer: { sec: 12, to: 'kushami.nowave', log: '迷っているうちに…' },
    log: 'このページに来たときに「きろく」に残す文',
    get: 'このページで手に入るもの',
  },
]);
```

### 選択肢の出し方（`ui.type`）

| type | 見た目 | 追加で書くもの |
|---|---|---|
| なし | リンクの一覧 | |
| `buttons` | ボタンが横に並ぶ | |
| `split` | 左右の端にリンク（分かれ道など） | |
| `select` | プルダウンと決定ボタン | `label`, `submit` |
| `radio` | ラジオボタンと送信ボタン | `label`, `submit` |
| `check` | チェックボックス（いくつでも選べる） | `label`, `submit`, `to`, `log`（`{n}` が選んだ数）, `noneLog`, `noneSet` |
| `input` | 文字入力 | `name`, `submit`, `to`, `log`, `empty`（空のまま送ったときの行き先）, `emptyLog`, `emptySet` |

`timer` だけ書いて `choices` を書かなければ、「待つ」ページになります（時間がたつと次へ進む）。

本文の中に `[文字](ページid)` と書くと、文中リンクになります。本文には `<span class="sway">` のような HTML も書けます。`※` の入った行を `if` / `unless` で出し分けると注釈の番号がずれるので、注釈は出し分けのない行に書いてください。
