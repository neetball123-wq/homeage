# homeage

さわって選ぶ、短編ストーリーのサイト。

- 企画書：[docs/企画書.md](docs/企画書.md)
- 文章のルール：[docs/文章のルール.md](docs/文章のルール.md)

## 動かし方

`index.html` をブラウザで開くだけで読めます。GitHub Pages で公開する場合は、このリポジトリのルートをそのまま公開してください。

## ファイル

- `index.html`：ページの外枠（ヘッダー、きろくの板、確認の窓）
- `style.css`：見た目と動き
- `engine.js`：ページの表示、さわって選ぶ部品、時間制限、きろく
- `stories/`：短編の中身。1本につき1ファイル

選ぶ部品は `engine.js` に一度だけ作ってあります。短編を書くときは、文章と `ui.type` を書くだけです。

## ページの書き方

```js
HOMEAGE.add([
  {
    id: 'kushami.pick',              // 短編名.ページ名
    place: 'ゴロの村 ＞ 道',           // ヘッダーに出る場所
    text: [
      '拾うと、まだ少しあったかい。',
      '',                               // 空行。重ねるほど間があく
      '!「くしゃみだから」',              // ! 小石が落ちる（ゴロの人のセリフ）
      '@1~「……出ないの？」',            // ~ 砂がこぼれる（ささやき）
      '@7*ぶえっくし。',                  // * 画面がゆれる
      '>少し先で、おばさんが…',            // < 左から　^ 中央（ふつう）　> 右から
      '「ウキシズ※より遠い？」',           // ※ を押すと notes の注釈が出る
      '「{{from}}、ねえ」',               // 入力された文字を出す
      { if: 'waved', text: '…' },       // フラグがあるときだけ出す（unless で逆）
    ],
    notes: ['ウキシズ　気持ちで体の重さが変わる人たち。'],
    ui: { type: 'drag', hint: '石をつまんで、運ぶ' },
    choices: [
      { text: '耳に当てる', to: 'kushami.ear', log: 'きろくに残す文', set: { ear: true } },
      { text: 'おばさんに返す', to: 'kushami.giveback' },
      { text: '何もしない', to: 'kushami.x', alt: true },   // alt は部品の下に小さいリンクで出る
    ],
    timer: { sec: 12, to: 'kushami.nowave', log: '迷っているうちに…', label: '待つ' },
    log: 'このページに来たときに残す文',
    get: 'このページで手に入るもの',
  },
]);
```

`@1`〜`@7` は文字の大きさ（ふつうは `@3`）。記号は `@5>!` のように組み合わせられます。

### 選ぶ部品（`ui.type`）

| type | さわり方 | choices の使われ方 | ui に書くもの |
|---|---|---|---|
| なし | リンクを押す | 全部 | |
| `buttons` | ボタンを押す（カーソルに寄ってくる、波紋が出る） | 全部 | `label` |
| `cards` | カードを1つ選んで決定（カーソルの向きに傾く） | 全部 | `label`, `submit` |
| `chips` | いくつでも選んで決定（数がバッジに出る） | 選んだものの `set` が全部効く | `label`, `submit`, `to`, `log`（`{n}` が数）, `noneLog`, `noneSet` |
| `select` | ドロップダウンから選んで決定 | 全部 | `label`, `submit` |
| `input` | 文字を書いて送る | 使わない | `label`, `live`, `submit`, `name`, `to`, `log`, `empty`, `emptyLog`, `emptySet` |
| `drag` | つまんで、どれかの枠に運ぶ | 枠になる | `hint` |
| `hold` | 長押し。押した長さで選ぶものが変わる | 短い順 | `label`, `hint`, `steps`（切りかわる秒数） |
| `swipe` | カードを左右にはらう | 1つめが左、2つめが右 | `card`, `hint` |
| `rub` | 押したまま左右にこする | 1つめ | `label`, `hint`, `count` |
| `spot` | 暗いところをなぞってのぞく | 1つめ（`key` を見つけると押せる） | `hidden`（`text`, `x`, `y`, `key`）, `bg`, `hint` |
| `spots` | 場面の中の点を押す | choices に `x`, `y`（%）を書く。`shape: 'stone'`、`fx: 'rollin'` も使える | `ratio`, `decor`, `hint` |

`timer` だけ書いて `choices` を書かなければ、「待つ」ページになります（時間がたつと次へ進む）。

本文の中に `[文字](ページid)` と書くと文中リンクに、`<span class="sway">` と書くとゆれる文字になります。`※` の入った行を `if` / `unless` で出し分けると注釈の番号がずれるので、注釈は出し分けのない行に書いてください。
